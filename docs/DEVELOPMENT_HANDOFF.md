## v29 · 중기·단기 항목 연결과 통계 막대

2026-10-09 추가 요청을 반영했다. 시간 기록 항목은 중기와 단기 목표 모두 직접 연결한다. 중기 목표 편집에는 시간 기록 항목과 하위 단기 목표를 함께 선택할 수 있다. 한 항목이 여러 목표와 겹치면 시간 메뉴에서 기록별 목표 하나를 배정한다. 상위 목표에는 한 번씩 합산하며, 중기 직접 배정분을 하위 단기 목표로 역분배하지 않는다. 기존 적용일 이력·단기 링크·백업은 유지한다. 활동 대상 검증을 중기/단기로 확장했으며 schemaVersion은 1이다.

주별·월간·연간의 항목별 달성률 칸을 가로 막대로 변경했다. 작은 비율 숫자를 함께 유지하고, 절제 초과는 붉은 줄무늬와 초과 사용 문구로 구분한다. 100% 초과는 실제 수치를 유지하되 막대 폭을 제한한다. 예산 없는 항목은 계산 제외를 표시한다. 월간/연도별 비교의 점수·증감률 계산은 변경하지 않았다.

검증: 새 목표 모델 검사 3개와 화면 검사 2개의 수정 전 실패를 확인한 후 구현했다. 전체 Node 389개, Chromium/WebKit 브라우저 60개, 배포용 자산 빌드와 diff 검사가 통과했다. 독립 코드 검토에서 수정 필요 사항이 없었다. 실제 통계 렌더러의 합성 데이터 화면을 PC/휴대폰 크기로 확인했다. 목표 저장·배정·재접속 검사는 합성 자료를 사용했으며, 사용자 운영 데이터에는 쓰지 않았다.

릴리스 식별자는 `2026.10.09-life-v29`이다. 배포 확인 시 운영 `release.json`의 build와 commit을 현재 main에 대조한다. 이 컴퓨터의 최근 실행 증거와 배포 확인 결과는 Git에서 제외한 `local-data/latest-verification.json`에 기록한다. 새 작업은 이 절의 중기·단기 직접 연결 규칙을 과거 단기 전용 기획보다 우선한다.

## v30 · 숫자 목표, 간결한 카드와 메뉴 분리

2026-10-09 최신 사용자 요청:

- 메뉴 순서는 대시보드 → 시간기록 → 시간예산 → 목표설정 → 통계 → 앱 설정이다. 예산은 원래 일간·주간 기능을 유지한 별도 메뉴이며, 목표설정은 새 goals 뷰이다. 모바일 메뉴는 바깥 영역 탭·메뉴 재탭·메뉴 선택·Escape로 닫힌다. WebKit의 빈 영역 탭에서 click 없이 pointerdown만 전달되는 경우도 처리한다.
- 숫자 목표는 시작값·목표값·단위와 날짜별 현재값을 사용한다. 중기 목표의 체중 예시 80→70kg, 현재 75kg은 50%이다. 증가·감소·목표 0·100% 초과·목표 반대 방향을 지원한다. 현재값은 절대값이며 합산하지 않는다. 미측정과 0을 구분하고 결과 자동 완료는 하지 않는다. 이전 백업에서 시작값이 없으면 0으로 해석하며, 오래된 0 목표는 비율 없이 보존한다.
- 목표 카드는 여백·글자·막대 크기를 줄이고 더 많은 카드를 배치한다. 목표 상세에서 보관·삭제한다. 보관은 기본 목록·대시보드·목표통계에서 숨기고 접힌 보관 목표 영역으로 옮긴다. 보관 해제·수정 시 연결을 다시 선택한다. 삭제는 확인 후 표시에서 제거하되 원본 기록과 하위 목표를 삭제하지 않는다.
- 통계의 여섯 번째이자 마지막 버튼이 목표통계이다. 이 모드에서만 목표 패널을 보이며, 일반 시간 통계 로드가 지연·실패해도 전환할 수 있다. 독립 체중 기록과 주간 점검 UI는 제거했다. 기존 weights/reviews 자료는 백업 호환을 위해 유지하고 신규 UI에서 쓰지 않는다.
- 수동 기록은 날짜·항목·분·선택 메모만 사용한다. 시작·종료 시각 및 입력 방식 선택 버튼은 제거하고, 오래된 시각 입력 선호도도 분 입력으로 정규화한다. 타이머·이전 시각 기록·점수·오프라인 큐는 유지한다. 기록 필드의 너비·높이·테두리를 통일하고 메모만 여러 줄로 표시한다.

데이터 확장: schemaVersion 1을 유지하며 goal version의 resultStart, goal의 deletedDate, 선택형 retainedEntryPaths를 추가했다. 보관·삭제 전에 해당 날짜 이후 이미 존재하는 기록의 목표 경로만 보존한다. 시간 원본이나 분 값은 복제하지 않는다. 같은 날 새로 만든 기록에는 종료된 링크를 적용하지 않으며 기존 기록의 시간 정정은 집계에 반영한다. 명시적 목표 재배정은 보존 경로를 해제한다. 오래된 날짜 기록은 원래 유효 기간 경로를 따른다.

회귀 검증은 실제 운영 자료를 변경하지 않고 합성 기록으로 수행한다. 보관·삭제로 당일 상위 누적이 사라지는 문제를 재현 후 고쳤고, 보존된 배정을 사용자 화면에서 다시 선택할 수 있도록 검토 피드백을 반영했다. 릴리스는 `2026.10.09-life-v30`이며 배포 커밋·검사 수·실행 주소와 최종 증거는 `local-data/latest-verification.json`에 기록한다.
